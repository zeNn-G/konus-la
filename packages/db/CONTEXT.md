# DB

Drizzle ORM over libSQL/Turso. Schema lives in `src/schema/`; migrations are generated from it via `drizzle-kit`.

## Language

- **User** — identity record (one per email).
- **Instance Owner** — the single **User** who owns the whole self-hosted instance: the one whose Better Auth global `role` is `admin` (via the admin plugin). The first account ever registered becomes the owner, bypassing the invite gate; everyone after needs a **SignupCode**. Owns code minting and instance-level moderation (instance-ban). Distinct from a **Guild Admin**, which is per-guild and never carries the global `admin` role.
- **Username** — a **User**'s unique, immutable `@mention` handle (`^[a-z0-9_]{3,20}$`, lowercased). Not a sign-in identifier — sign-in is email + password. The only profile column added in Phase 1. Reserved (rejected at signup): `everyone`, `here`, `admin`, `system`, `owner`. Validation + reserved-list live in `src/constants.ts`. Immutability is enforced by a Better Auth `user.update` hook that strips the field.
- **displayName** — the mutable name shown in chat. This **is** Better Auth's `name` column, not a separate field. Defaults to the username at signup when left blank.
- **avatarUrl** — this **is** Better Auth's `image` column. Nullable; the client renders a deterministic Dicebear avatar (seeded by username) when null. No setter in v1 (object storage is post-v1), so it stays null.
- **role / banned** — supplied by the Better Auth **admin plugin** (`role`, `banned`, `banReason`, `banExpires`), not hand-rolled. The Instance Owner has `role='admin'`; **instanceBanned** is `banned`. See [ADR 0002](../../docs/adr/0002-two-tier-authorization.md).
- **SignupCode** — a single-use invitation token granting the right to register one account. Has an optional `expiresAt`; claimed atomically at signup via a conditional `WHERE usedAt IS NULL` update (`usedAt` + `usedByUserId` set). Minted by the **Instance Owner**. The zero-users bootstrap signup needs no code. `revoke` hard-deletes a still-unused row; claimed rows are kept as a record. Query helpers live in `src/queries/` so `@konus-la/auth` and `@konus-la/api` never import `drizzle-orm`.
- **Guild** — a self-contained server **User**s belong to (and later, its channels). Owned by exactly one **User** via `ownerId` — never a role row (see [ADR 0004](../../docs/adr/0004-per-guild-authorization-custom-rbac-tables.md)). Non-unique `name`; nullable `icon` (client renders a Dicebear `identicon` seeded by the guild id when null). The `MAX_GUILDS_PER_USER` cap counts **owned** guilds only.
- **GuildMembership** — a **User**'s membership in a **Guild** (PK `(userId, guildId)`). The owner holds a row like everyone else. Membership alone _is_ the implicit **@everyone**. `serverMuted` is the persistent server-mute flag (Phase 6): it survives voice leave/join and server restarts — voice rooms are in-memory, the flag is not.
- **GuildRole** — a role within one **Guild**. Every guild seeds exactly one, `isDefault: true` marking the implicit **@everyone** (identified by the flag, never the name). `permissions` is the RBAC bitfield ([ADR 0008](../../docs/adr/0008-rbac-activation-permission-bitfield.md)): a plain JS number whose bit meanings live in `@konus-la/api/permissions` — this package traffics in **raw integers only**. `color` (`#rrggbb`, null = uncolored) tints names; higher `position` = higher rank, **@everyone pinned at 0**.
- **MemberRole** — assignment of a non-default **GuildRole** to a member (the default role is never materialised here). **Effective permissions** = OR of the member's rows plus the `isDefault` row — `getEffectivePermissions` (one query, OR'd in JS, fresh per gated request, no cache). Hierarchy helpers live beside it in `queries/permissions.ts`: `getMemberAccess` (membership + ownership in one query, the gates' first step), `getHighestRolePosition` (max position, 0 with none), and `actorOutranksMember` (target-is-owner → false, actor-is-owner → true, else strict `actorPos > targetPos` — equal rank and self-target both fail). Role CRUD movers live in `queries/roles.ts`: `createGuildRole` (bottom-insert at position 1, existing customs shift up), `updateGuildRole`, `deleteGuildRole` (memberRole rows cascade), `getAdjacentGuildRole` + `swapGuildRolePositions` (adjacent-swap reorder — positions keep gaps, ordering is relative); hierarchy/escalation checks stay in the api router.
- **Report** — a member's report of a **Message**, scoped to one **Guild** (DMs are never reportable). ULID text PK. `messageContent` is a **snapshot at report time** and the `messageId` FK goes NULL on hard-delete — the report survives the message. Resolution is a mark (`resolvedAt`/`resolvedById`, no FK), never a forced action.
- **AuditLogEntry** — a forensic record of one privileged mutation in a **Guild**. ULID text PK doubles as the pagination cursor. `actorId` and the target columns carry **no FKs, deliberately** — entries must survive the deletion of what they reference; only `guildId` cascades (guild gone = log gone). `metadata` is a JSON string (changed fields as `[old, new]` pairs).
- **GuildInvite** — a shareable, multi-use invite code for a **Guild**. Time-only expiry (`expiresAt` nullable = never); `usedCount` is display-only (no max-uses cap). Consumed atomically (ban check → already-member no-op → insert membership + tick `usedCount`); revoke hard-deletes.
- **GuildBan** — a **User** barred from rejoining a **Guild** (PK `(guildId, userId)`). A ban beats an invite (checked in `consumeInvite`).
- **Channel** — a place **Message**s live: belongs to a **Guild** (`guildId` + slug `name`, unique per **(guild, kind)** — so a voice `general` may sit beside a text `#general`; nothing resolves a channel by name) or is a DM (`guildId` null, participants in **ChannelParticipant**). `kind` is `text | voice | dm`; guild channels are creatable as `text` or `voice` (`createChannel` demands `kind`; `channel.create` defaults it to `text` and refuses `dm`). `guild.create` seeds a `#general`. Hard delete cascades messages.
- **DM (1:1 vs group)** — two distinct flavors of `kind: 'dm'`, split by `channel.isGroup` (see [ADR 0006](../../docs/adr/0006-participant-keyed-dm-channels.md)). A **1:1** is THE unique conversation between two **User**s: `dmPairKey` (sorted `"idA:idB"`) has a unique index — SQLite treats NULLs as distinct, so guild channels and groups (both NULL) never participate — making `dm.openWithUser` race-proof idempotent. Created lazily on the first message (draft flow), never renamed, never gains a third member. A **group** is created explicitly (≥3 people, capped by `MAX_DM_GROUP_SIZE`), has a nullable free-text `name` and an owner (`channel.ownerId` — ADR 0004 column-not-flag precedent; NULL for guild channels and 1:1s). The kind/isGroup/dmPairKey/ownerId invariant is enforced by the two creation paths in `queries/dm.ts`, not a CHECK constraint.
- **ChannelParticipant** — a **User**'s membership in a DM **Channel** (PK `(userId, channelId)`, `joinedAt`). Membership is the ONLY key to a DM's history: leaving or being removed deletes this row **and the user's ChannelReadState row** (so a re-add starts fully unread instead of inheriting a stale watermark). The last leaver's delete removes the channel itself (cascade). Owner-leave hands `ownerId` to the longest-standing participant (earliest `joinedAt`, then lowest `userId`).
- **Message** — a text post in a **Channel**. **ULID text PK** (via the `ulid` package's `monotonicFactory`): lexicographic order IS chronological order, so cursor pagination and newest-message reduce to string comparison on the `(channelId, id)` index. `replyToMessageId` self-FK goes NULL when the parent is hard-deleted; `editedAt` is the only edit record. Mentions (`@username`, parse helpers in `src/mention.ts`) are resolved **on insert only** — against guild members for guild channels, against **ChannelParticipant**s for DMs.
- **ChannelReadState** — per-user per-channel read watermark + mention counter (PK `(userId, channelId)`). `lastReadMessageId` is a **watermark, not an FK** — it stays ULID-comparable after the message it names is deleted. Upserted forward-only (`setWhere` guard) so a stale tab never rewinds a fresher device; rows are created lazily; missing row = everything unread.
- **Session** — a live login, belongs to a **User**.
- **Account** — a sign-in credential (email/password or OAuth) attached to a **User**. Not a billing/tenant account.
- **Verification** — one-shot token (email verify, password reset).
